# XXCK

XXCK 项目仓库。

## 目录说明

- `.github/ISSUE_TEMPLATE/` — Issue 模板
  - `bug_report.md` — Bug 反馈（默认标签 `bug`）
  - `feature_request.md` — 功能需求（默认标签 `enhancement`）
  - `config.yml` — 关闭空白 Issue，强制使用模板

## 约定

- 主分支：`main`
- 提交信息建议遵循 Conventional Commits（如 `feat: xxx` / `fix: xxx`）
- 反馈问题请使用对应 Issue 模板
